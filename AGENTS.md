# Moon Cat Launcher
Preserve GPL-3.0 and upstream attribution. Kotlin-first, Android API 28+, Spanish and English. Keep main stable; work on feature branches. Never add INTERNET, telemetry, ads, remote APIs, cloud sync or automatic update checks. Audit merged manifests and all dependencies. Third-party widgets may use their own network permissions; warn users. Sensitive permissions must be optional where feasible. Never commit signing keys or credentials. Do not claim security or offline compliance until verified. Keep existing features unless explicitly superseded. Default text-only UI. Add tests for security-sensitive changes. Biblical texts: the owner chose John 3:16-17 for About (Spanish text supplied by the owner; English is the public-domain Douay-Rheims, pending owner confirmation). Daily verses come only from the owner: keep mooncat_verses.xml empty until they supply them, and never write verse texts yourself.
